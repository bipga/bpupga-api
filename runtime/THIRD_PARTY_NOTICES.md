# Component notices

The engine includes the twelve implementations used by the BiPGA artifact,
their shared records, GPU numerical routines and required model weights.
Upstream source notices remain in the bundled files.

- `bpupga/_engine/baseline/vendor/`: upstream method implementations.
- `bpupga/_engine/baseline/opgm_unsupervised/vendor/LICENSE`: OPGM component license.
- `bpupga/_engine/baseline/opgm_unsupervised/python_deps/`: bundled dependencies and their license notices.
- `bpupga/_engine/baseline/ulot/`: model implementation and required checkpoint.

The distribution does not grant additional rights to components whose source
did not include a license. Dependency packages retain their own licenses.
